# Metric Rules – Startvärden (januari 2026)

1. ai_capability dubbleras varje halvår (från 3 vid start)
2. När ai_capability ökar snabbt trycks ai_adoption_sweden ned, i och med att färre sannolikt har tillgång till *frontier* AI (som flyttats)
3. Hög unemployment minskar public_sentiment_to_ai
4. Snabb ökning av ai_capability utan motsvarande ökning av ai_adoption_sweden minskar public_sentiment_to_ai
