## What this bank does NOT cover (Known Gaps)

1. Exact tech-tree node names and R&D costs (unpublished assets). Handle as: abstract capability levels 0–4; note in design-notes.
2. Exact victory-condition text and dice tables (facilitator-held). Handle as: termination conditions on capability/safety/stability/tension; note in design-notes.
3. Real 2026 starting values for talent/compute stocks (commercially opaque). Handle as: relative starts (US slightly ahead) marked [assumption].
4. Whether the 2028/2032 elections go disruptive (unknowable). Handle as: certain election events, disruptive outcome resolved in narrative + metric rules, not hard-coded.
5. Startup/open-source breakthrough specifics. Handle as: generic diffusion-shock event.
6. Verification-regime technical content. Handle as: agreement_strength with reference points; detailed designs left to actor negotiation.
