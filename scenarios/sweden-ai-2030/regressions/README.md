# Sweden AI 2030 Regression Examples

These manifests use real saved runs from `scenarios/sweden-ai-2030/runs/`.

Examples:

```bash
python -m scenario_lab.cli check-regressions scenarios/sweden-ai-2030/regressions/pairwise-example.yaml
python -m scenario_lab.cli compare-distributions scenarios/sweden-ai-2030/regressions/distribution-example.yaml
```

These are examples for inspection and workflow bootstrapping, not claims that one run set is the canonical "correct" outcome.
