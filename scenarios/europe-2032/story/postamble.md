# This is a simulation, not a forecast

This story is not a forecast. It is one path the world could take, picked at random from many simulations.

Also, there is no grand ending. This is simply where the simulation stops.

The simulations are generated with a tool called [Scenario Lab](https://github.com/Itangalo/scenario-lab), using LLMs both as the actors and as the referee that decides how the world unfolds. The simulations build on a combination of plain-text descriptions and semi-rigid rules for how metrics in the world evolve and interact.

The idea behind Scenario Lab is to make scenario gaming cheap and quick. When you can run hundreds or thousands of simulations, you have a useful tool for exploring typical outcomes, pivotal events and decisions, and which factors tend to lead to good or bad world states.

The world we live in is changing rapidly. We need good tools for making robust decisions, even under deep uncertainty. LLM-powered simulation is a tool that can improve with the same rate as LLMs.
