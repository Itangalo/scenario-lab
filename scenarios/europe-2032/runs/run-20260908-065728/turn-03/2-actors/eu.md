This is no longer about resilience alone — it is about creating a shared operational picture across borders.

Meanwhile, the **Sovereign Model Access Programme** launches this turn to close a different gap: we can regulate and respond, but we still lack eyes on the frontier itself. These will run parallel to, but independently of, developer-run systems. Our leverage comes from market access: any provider seeking deployment in the Single Market at scale must allow a mirrored instance in one enclave. This does not give us control — but it gives us visibility, and that is the first condition of safety. We are already in talks with one US-based lab willing to comply in exchange for fast-tracked conformity assessment. It is a foothold, not a victory — but it is ours.
