# Draws-era archive, sealed 2026-08-26

Everything produced before the variant-patch conversion, kept for the draft
this material fed and for later reference. Nothing here is loaded by the
framework; new runs land in `../../runs/` and start from an empty slate.

Contents:

- `runs/` – all 84 runs of the draws era: 60 base (20 per arm via
  `draws/`), 9 sibling-era urgent runs, 15 urgent runs from 25–26 August.
  Per-run `analysis.json` files live inside each run directory.
- `synthesis.md` – pooled synthesis over the base scenario.
- `syntheses/` – per-cohort group syntheses behind the disposition comparison.
- `comparisons/` – the three urgent-vs-base stitched reports
  (`disposition-fast|plateau|rlvr-limited.md`) plus their input group reports.
- `emergent-catalogue.md` – catalogue of emergent events observed across runs.

Cohort keys for this era: base runs carry `arm=<fast|plateau|rlvr-limited>` in
`initial_state.notes`; the 24 urgent runs carry identity "Forking Futures —
Urgent Regulator" with the same notes. Later eras group by scenario name
instead.
