# AI Safety Race Regression Examples

These manifests use real saved runs from `scenarios/ai-safety-race/runs/`.

Examples:

```bash
python -m scenario_lab.cli check-regressions scenarios/ai-safety-race/regressions/pairwise-example.yaml
python -m scenario_lab.cli compare-distributions scenarios/ai-safety-race/regressions/distribution-example.yaml
```

These are examples for inspection and workflow bootstrapping, not claims that one run set is the canonical "correct" outcome.
